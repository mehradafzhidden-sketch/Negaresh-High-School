# مدرسه نگرش — نسخه آغازین

وب‌اپ فارسی و راست‌چین با Node.js، Express و PostgreSQL.

## اجرا
1. نصب Node.js نسخه 20 یا بالاتر.
2. اجرای `npm install`.
3. تنظیم متغیر محیطی `DATABASE_URL` با نشانی اتصال PostgreSQL.
4. اجرای `npm start` و بازکردن `http://localhost:3000`.

در شروع برنامه، جدول‌های `students` و `announcements` در صورت نبود ساخته می‌شوند و دو اطلاعیه آزمایشی درج می‌شود.

## API
- `GET /api/health` — بررسی اتصال پایگاه داده.
- `GET /api/announcements` — خواندن ۱۰ اطلاعیه آخر.
- `GET /api/students/count` — فقط شمارش دانش‌آموزان، نه پرونده‌ها.

## نکته امنیتی
این نسخه فقط نقطه شروع است؛ ورود امن، نقش‌ها و مجوزهای دسترسی، اعتبارسنجی فرم‌ها، پشتیبان‌گیری و ثبت رویدادهای مدیریتی هنوز پیاده‌سازی نشده‌اند. تا تکمیل این موارد، اطلاعات واقعی و حساس دانش‌آموزان را وارد نکنید. متغیر `DATABASE_URL` را هرگز داخل کد یا مخزن GitHub قرار ندهید.
